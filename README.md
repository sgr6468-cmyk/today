# 오늘한줄

하루의 끝에 한 줄만 남기는 일기장 앱이에요. Made by 백수마녀 (Day-Off Witch)

## APK 받는 법
1. 이 저장소에 파일을 올리면 자동으로 APK를 만들어요 (Actions 탭).
2. 초록 체크가 뜬 항목을 눌러 아래 Artifacts의 `oneline-apk`를 내려받아요.
3. 압축을 풀고 `app-release.apk`를 폰에 설치해요.

## 일기장 화면 고치기
`app/src/main/assets/index.html` 파일을 바꾸면 돼요.

## 알림
설정 > 저녁 알림에서 시간을 고르면 매일 그 시간에 알려줘요. 그날 이미 썼으면 건너뛰어요.
